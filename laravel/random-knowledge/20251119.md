## Tạo bảng `san_phams` bằng migration

Tạo model SanPham và migration đi kèm bằng lệnh

```bash
php artisan make:model SanPham -m
```

Ở file migration vừa tạo, thiết kế bảng `san_phams` có khóa ngoại, có index như sau:

```php
public function up(): void
{
    Schema::create('san_phams', function (Blueprint $table) {
        $table->id();
        $table->string('ten_san_pham')->nullable();
        $table->string('hinh_anh')->nullable();
        $table->text('mo_ta')->nullable();
        $table->decimal('gia_ban', 15, 0)->nullable();
        // khóa ngoại
        $table->bigInteger('id_danh_muc')->nullable();
        $table->bigInteger('id_thuong_hieu')->nullable();
        $table->bigInteger('created_by')->nullable();   // user_id tạo sản phẩm

        $table->timestamps();
        
        // index để tăng tốc xử lý khóa ngoại
        $table->index('id_danh_muc');
        $table->index('id_thuong_hieu');
        $table->index('created_by');
    });
    
    /*
     * Các dòng code khác
     */
}

```

Chạy lệnh để thực thi migration

```bash
php artisan migrate
```

## Tạo Controller Resource

Tạo `SanPhamController` trong thư mục `Controller/Admin` bằng lệnh

```bash
php artisan make:controller Admin/SanPhamController -r
```
Cũng tạo Route Resource cho controller vừa tạo. Thực hiện viết các chức năng CRUD như bình thường. Hiện tại chỉ thực hiện được 2 chức năng thêm và xem danh sách sản phẩm.

Đối với chức năng thêm cần lưu ý 1 số điểm như sau:

- Sử dụng `enctype="multipart/form-data"` cho thẻ `form` để có thể upload được ảnh.
- Sử dụng component `<x-input ... />` đã học hôm trước thay cho thẻ `input` truyền thống.
- Chỉnh sửa component `<x-input ... />` để có thể truyền động thuộc tính `type`

    ```html
    @props([
        'label',
        'name',
        'value' => '',
        'type' => 'text',   // thêm dòng này và sửa `type` của input
    ])

    <div class="mt-3">
        <label class="form-label">{{ $label }}</label>
        <input name="{{ $name }}" type="{{ $type }}" class="form-control"
            value="{{ old($name, $value) }}" />
    </div>

    ```

Dưới đây là form thêm mới sản phẩm sau khi áp dụng những thay đổi ở trên

```html
@include('app._error')
<form action="{{ route('admin.sanpham.store') }}" method="post" enctype="multipart/form-data">
    @csrf
    <x-input name="hinh_anh" label="Hình ảnh" type="file" />
    <x-input name="ten_san_pham" label="Tên sản phẩm" />
    
    {{-- Các input khác --}}

    <div class="mt3">
        <input class="btn btn-primary" type="submit" value="Thêm sản phẩm" />
    </div>
</form>
```

Hàm `store` trong SanPhamController được viết như sau:

```php
public function store(Request $request)
{
    $data = $request->validate([
        // bắt buộc, là file, phải là ảnh (jpeg, png,...), tối đa 4096KB (~4MB)
        'hinh_anh' => 'required|file|mimes:jpeg,jpg,png,webp|max:4096',
        'ten_san_pham' => 'required',
        'mo_ta' => 'required',
        'gia_ban' => 'required|numeric',
    ]);

    /*
     * Chức năng upload file
     */
    // Nhận file ảnh từ request
    $file = $request->file('hinh_anh');
    // Chỉ định thư mục lưu ảnh (trong thư mục public/uploads)
    $target = public_path('uploads');
    // Tạo tên mới với dạng <thời_gian_hiện_tại>_<tên_file_cũ> để tránh bị trùng tên
    $newFileName = time() . "_" . $file->getClientOriginalName();
    // Lưu file vào thư mục chỉ định với tên mới
    $file->move($target, $newFileName);

    // Cập nhật lại cột hình ảnh
    $data['hinh_anh'] = '/uploads/' . $newFileName;

    $sp = new SanPham($data);
    $sp->save();
    return redirect()->route('admin.sanpham.index');
}

```
